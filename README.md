#  To-Do List App

**Organize Your Tasks. Boost Your Productivity! **

##  About the Project

The To-Do List App is a simple web application designed to help users add, view, and manage their daily tasks.

I built this project as part of my journey as a Frontend Web Developer to improve my practical skills in HTML, CSS, and JavaScript.

##  Features

*  Add new tasks
*  Mark tasks as completed
*  Delete tasks
*  Simple and user-friendly interface
*  Responsive design

##  Technologies Used

* HTML5
* CSS3
* JavaScript

* Handling user interactions
* Updating webpage content dynamically
* Styling web applications with CSS
